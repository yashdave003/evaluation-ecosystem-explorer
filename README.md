# AI Evaluation Ecosystem Explorer

Interactive browser for simulation runs. Three pages:

| Page | Purpose |
|------|---------|
| `index.html` | Condition card grid with filters (bucket, mode, model, search) and compare mode |
| `viewer.html` | Full animated single-run playback — fetched via `?run=<path>` |
| `compare.html` | Multi-run comparison: condition selector + seed selector + p10/p90 aggregate option |

## Running locally

```
cd web-explorer
python -m http.server 8080
# open http://localhost:8080
```

The `data/` directory and `runs.json` are generated by the simulation repo and excluded from git.

## Regenerating data

```
cd evaluation-ecosystem-simulation
python scripts/animation/generate_explorer.py
# writes ../web-explorer/data/ and ../web-explorer/runs.json
```

## URL formats

```
index.html?bucket=core_privacy&mode=llm&model=claude-sonnet-4-6&q=baseline

viewer.html?run=core_privacy/llm/claude-sonnet-4-6/baseline/seed_42

compare.html?conditions=baseline|public_only&seeds=seed_42&model=claude-sonnet-4-6
compare.html?conditions=baseline&seeds=seed_42|seed_43&model=claude-sonnet-4-6&agg=1
```
